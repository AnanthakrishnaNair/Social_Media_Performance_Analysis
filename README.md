# Spotify Social Media Performance Analysis

## Project Overview

This project analyzes Spotify's social media marketing performance across multiple platforms, including Instagram, Twitter, Facebook, and YouTube. The objective is to transform raw marketing data into meaningful business insights that help improve campaign effectiveness, audience engagement, and return on marketing investment.

The analysis was completed using Microsoft Excel by applying data cleaning techniques, Pivot Tables, formulas, charts, and business intelligence concepts to answer real-world marketing questions.

---

## Business Problem

Spotify runs multiple marketing campaigns throughout the year to promote artists, playlists, podcasts, and premium subscriptions. However, measuring campaign effectiveness across different social media platforms is challenging.

The marketing team wanted answers to questions such as:

* Which platform generates the highest engagement?
* Which content type performs best?
* Which hashtags increase audience interaction?
* Which campaigns deliver the highest ROI?
* How does advertising spend influence follower growth and app downloads?

This project provides a data-driven solution to these questions.
